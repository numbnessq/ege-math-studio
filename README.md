# Разлиновано

Конструктор тренировок по профильной математике ЕГЭ. Откройте `index.html` в браузере, в том числе без подключения к сети. Сайт работает и на любом статическом хостинге.

Выберите номер и тип задачи или полный вариант. Один комплект включает от одной до четырёх работ. Для каждой позиции генератор один раз выбирает шаблон и выдаёт разные числа без повторов внутри комплекта. В собранном варианте можно отфильтровать задания по теме или заменить одно задание внутри той же части экзамена. Геометрические чертежи и графики строятся по числам конкретной задачи. «Печать» выводит весь комплект, затем ключи для учителя по вариантам.

## Банк

В scripts/templates.mjs находятся параметрические задачи и три адаптированных примера из [методических рекомендаций ФИПИ](https://doc.fipi.ru/navigator-podgotovki/navigator-ege/MR_matematika_ege_2026.pdf). Источник и исходные числа доступны в отдельном режиме. Сгенерированные версии помечены как авторские аналоги. Нумерация соответствует формату с 12 короткими и 7 развёрнутыми ответами. Это стартовый набор типов внутри экзаменационных номеров.

Node.js 24 нужен только для обновления банка и тестов.

```sh
node scripts/build.mjs
node --test tests/generator.test.mjs
```

Сборка записывает материал в data/bank.sqlite и выгружает таблицы в data/bank.js для статического сайта. Добавляйте типы через templates, а проверенные первоисточники — через originals. Размер серии ограничен четырьмя. Изменяя диапазон параметров, проверяйте область допустимых значений и конечность десятичного ответа в первой части.
